# 🖼️ FakeNFT

Мобильное iOS-приложение для просмотра и покупки **NFT** (Non-Fungible Tokens).  
Функция покупки реализована через **mock-сервер**.   

---

## 🚀 Технологии

- **Язык:** Swift 5.x  
- **Фреймворк:** SwiftUI  
- **Архитектура:** MVVM  
- **Минимальная iOS:** 17.0  
- **Concurrency:** `async/await`, `actor`, `Sendable`, `@MainActor`  
- **Локальное хранение настроек:** `@AppStorage` / `UserDefaults`  
- **Сеть:** Mock API (асинхронные запросы)  

---

## ✨ Основные возможности

- 📂 Каталог NFT, структурированных в коллекции  
- 🔍 Просмотр информации о коллекциях и отдельных NFT  
- ❤️ Добавление NFT в избранное  
- 🛒 Корзина: добавление, удаление, сортировка, имитация оплаты  
- 📊 Рейтинг пользователей и их профили  
- 👤 Личный профиль: мои NFT, избранное, редактирование данных  
- 🎨 Поддержка светлой и тёмной темы  

---

## 📱 Основные экраны

### 📂 Каталог
- Список коллекций NFT (`List`)  
- У каждой коллекции: обложка, название, количество NFT  
- Кнопка сортировки коллекций  
- Индикатор загрузки (`ProgressView`)  
- Переход к экрану коллекции  

### 🖼️ Коллекция NFT
- Обложка, описание и автор коллекции  
- NFT-сетка (`LazyVGrid`):  
  - Изображение, название, рейтинг, цена (ETH)  
  - ❤️ Избранное  
  - 🛒 Добавление/удаление в корзину  
- Переход на экран отдельного NFT  

### 🛒 Корзина
- Таблица (`List`) с NFT  
- Удаление с подтверждением  
- Панель внизу: количество, сумма, кнопка оплаты  
- Оплата с выбором валюты (`LazyVGrid`)  
- Веб-вью с пользовательским соглашением  
- Обработка ошибок и повторные запросы  

### 👤 Профиль
- Фото, имя, описание, сайт  
- Разделы: «Мои NFT», «Избранные NFT»  
- Возможность редактировать профиль  

### 📊 Рейтинг
- Таблица пользователей: место, аватар, имя, количество NFT  
- Переход к профилю пользователя и его коллекциям  

---

## ⚙️ Сортировка данных

- Доступна в: Каталоге, Корзине, Моих NFT, Рейтинге  
- Настройки сохраняются и восстанавливаются при перезапуске  
- Значения по умолчанию:  
  - Каталог — по количеству NFT  
  - Корзина — по названию  
  - Мои NFT — по рейтингу  
  - Статистика — по рейтингу

## 🛠 Архитектура и код

- `ViewModel` реализован через `@Observable` или `@Published` (ObservableObject)  
- Используются модификаторы состояния:  

`@State           – локальное состояние View`
`@Binding         – передача состояния между View`
`@StateObject     – хранение ViewModel`
`@ObservedObject  – подписка на ViewModel`
`@EnvironmentObject – общие данные`

* Сеть: асинхронные запросы (`async/await`)
* Акторы (`actor`) для потокобезопасности
